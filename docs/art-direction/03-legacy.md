# 03 — THE LEGACY

## Referências observadas
- Scrapbook vintage: foto com cantos de papel/fita sobre textura de papel —
  o tratamento de época mais convincente vem de CAMADAS, não de filtro.
- Spread do Rooney (Man Utd): foto principal + foto menor sobreposta atrás,
  deslocada, + colunas de metadados datilografados.
- Poster retrô Ronaldo Nazário: bloco de cor + nome gigante na base.
