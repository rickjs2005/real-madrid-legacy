## Aprendizados transversais (confirmados nos premiados)

1. **Preto + branco + navy profundo + dourado contido** é a paleta canônica do
   premium — estamos nela; disciplina é não adicionar cor.
2. **Tipografia oversized É a hierarquia** — mas os melhores variam a composição:
   texto cruzando a foto, captions em barra fina, baselines desalinhados.
3. **Fotografia em camadas** (colagem editorial, imagem sobreposta a imagem,
   fita/moldura de papel no vintage) é o que separa "site com fotos" de
   "direção de arte". É a nossa maior lacuna.
4. **Metadados como elemento gráfico**: os spreads bons carregam legendas
   tipo ficha técnica (data · local · competição) em corpo pequeno com tracking.
   Já usamos nas molduras do Legacy — expandir.
